# portfoly_f

Temeloji Dijital web sitesi. Next.js App Router, TypeScript, Tailwind CSS ve MongoDB kullanır.

## Geliştirme

```sh
npm install
npm run dev
```

Siteyi `http://localhost:3000` adresinde açın. Yerel ortam değişkenlerini `.env.local` dosyasında tanımlayın; bu dosya Git'e eklenmemelidir.

İlk yönetici hesabını kurmak için `npm run admin:setup` komutunu kullanın.

## Kontroller

```sh
npm run lint
npx tsc --noEmit
npm run build
```
